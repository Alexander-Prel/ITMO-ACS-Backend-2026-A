Для продолжения используются учебная Ubuntu 24.04, учебный кластер с default StorageClass, LoadBalancer и Metrics API, доступ на запись в форк с GitHub Actions и доступ на чтение образов в кластере. Выделение ресурсов и реальные расходы не зафиксированы. Параметры окружения и права для каждого этапа перечислены в README соответствующей работы.

Доступ к учебной инфраструктуре пока отсутствует. Для завершения нужны выделенная Ubuntu-ВМ с Docker и SSH, а также Kubernetes с RWO-хранилищем, доступом к реестру и Metrics API. В README преподавателя предусмотрена возможность запросить вычислительные ресурсы лично. Проектный вариант с двумя worker-узлами можно уточнить под выданную квоту.
