# Бронирование столиков

Клиент регистрируется, выбирает ресторан, бронирует столик и получает уведомление. Все клиентские запросы принимает Gateway. В ответах используются JSON, числовые идентификаторы и даты брони в формате YYYY-MM-DD. Поиск ресторана доступен без регистрации.

| Компонент | За что отвечает | Данные |
| --- | --- | --- |
| Gateway | Принимает публичные запросы и проверяет готовность зависимостей | Без состояния |
| Accounts | Регистрация, вход, профиль, проверка JWT | Пользователи |
| Catalog | Поиск, категории цен, меню, отзывы, столики | Каталог |
| Bookings | Проверка доступности и изменение брони | Брони и outbox |
| Notifications | Получение событий и выдача уведомлений пользователю | Уведомления |
| RabbitMQ | Доставка событий создания и отмены | Устойчивые очереди |
