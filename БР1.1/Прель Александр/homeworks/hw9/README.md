# ДЗ9. Документация приложения

Из этой директории установите зависимости из requirements.txt в отдельный venv. Команда python build-contracts.py собирает два OpenAPI 3.0.3 документа и копирует согласованную коллекцию Postman вместе с окружением. Команда mkdocs build --strict собирает сайт. Для просмотра используйте mkdocs serve. В docs доступны обзор, сценарий пользователя и эксплуатация. В Swagger Editor можно открыть docs/downloads/openapi.json. Внутренний API опубликован отдельно для разработчика.
