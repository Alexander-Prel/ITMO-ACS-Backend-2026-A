# ЛР4. Развёртывание на выделенной Ubuntu 24.04

Состав пакета: production Dockerfile ЛР3, исходники ЛР2, Docker Compose, контейнер Nginx с внутренней сетью и внешний системный Nginx. Контейнеры и секреты из сентябрьского стенда не переносятся.

1. Перенесите исходники на выделенную учебную ВМ. Запустите из этой папки bash prepare-vm.sh от имени обычного пользователя с sudo. Сценарий установит Docker, Compose, Nginx, создаст постоянную конфигурацию /opt/itmo-booking/shared/.env.compose и настроит внешний порт 8080. Переподключитесь по SSH для применения группы docker.
2. Из корня checkout выполните команды ниже. Для учебной ВМ разрешите поступление трафика на TCP/8080 от клиента проверки.
3. С отдельной машины проверьте GET /ready и Postman. Сохраните дату, версию, логи проверки и вывод docker compose ps. Локальные тесты сентября описаны в TEST_RESULTS_2026-09-10.md.

~~~bash
revision=$(git rev-parse HEAD)
git archive --format=tar.gz --output="/tmp/itmo-backend-$revision.tar.gz" "$revision"
bash 'БР1.1/Прель Александр/homeworks/hw6/scripts/remote-deploy.sh' /opt/itmo-booking "$revision"
curl --fail http://127.0.0.1:8080/ready
~~~

Внешний Nginx принимает запрос на порту 8080, локальный Nginx контейнера доступен только на 127.0.0.1:8200. Порты прикладных сервисов и RabbitMQ на интерфейс ВМ не публикуются. Повторный деплой сохраняет секреты и именованные тома. При неуспешном развёртывании для восстановления приложения повторно примените архив проверенной ревизии.

Актуальный прогон: [Backend CI/CD 44517314031](https://github.com/Alexander-Prel/ITMO-ACS-Backend-2026-A/actions/runs/44517314031). На Ubuntu прошли 3 теста Nginx, smoke и 117 утверждений Postman. Проверка сохранности данных при повторном развёртывании успешна. Внешний постоянный адрес ещё не предоставлен.
